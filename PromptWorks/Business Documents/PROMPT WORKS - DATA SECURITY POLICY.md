PROMPT WORKS - DATA SECURITY POLICY
How we protect your confidential information


OUR PROMISE TO CLIENTS
✅ Your data stays private ✅ Files deleted after project completion ✅ No sharing with third parties ✅ Secure transfer methods only ✅ NDA available upon request


WHAT WE DO WITH YOUR FILES
DURING THE PROJECT:
Store files locally on password-protected computer
Work offline when possible
No cloud storage of sensitive data (unless you approve)
No AI training on your confidential data
AFTER PROJECT DELIVERY:
Delete all client files within 7 days
Delete credentials/API keys immediately
Retain only anonymized project documentation
Keep financial records only (for taxes)


FILE TRANSFER METHODS
WE ACCEPT: ✅ Fiverr/Upwork platform uploads (encrypted) ✅ Google Drive shared links ✅ Direct email (for non-sensitive files)

WE NEVER USE: ❌ Public file-sharing sites ❌ Unencrypted email for sensitive data ❌ Personal cloud storage without permission


FOR DATABASE PROJECTS
Access Database (.accdb) files:

You send us the file
We work on it locally (offline)
We test thoroughly
We send it back
We never access your live systems remotely

What we see:

Your database structure
Your data (to test functionality)
Your business processes

What we protect:

Customer information
Financial data
Proprietary business information
Trade secrets


CREDENTIALS & API KEYS
If your project requires API keys or passwords:

✅ Share via secure method (platform message, encrypted file)
✅ We use them only for your project
✅ We delete them immediately after delivery
✅ We never save them in our systems
✅ We recommend you rotate/change them after project completion


NON-DISCLOSURE AGREEMENTS (NDAs)
We're happy to sign:

Standard NDAs
Mutual NDAs
Industry-specific confidentiality agreements

Just ask before project start.


WHAT WE KEEP (For Our Records)
We retain:

Project descriptions (anonymized)
Payment records (tax requirement)
Communication history (platform messages)

We delete:

Your actual files
Your data
Your credentials
Anything proprietary


YOUR RIGHTS
You can:

Request immediate deletion of all files
Ask for proof of deletion
Require additional security measures
Specify custom data handling requirements


QUESTIONS?
Ask before the project starts. We'll clarify exactly:

What data we need access to
How we'll protect it
When we'll delete it
What security measures apply
