HOW TO USE THESE
Open CiC (Claude in Chrome)
Copy ONE prompt exactly as written
Paste it into CiC
Tell CiC: no analysis, just do the task
Watch what it does -- step in if it gets stuck
Run each prompt in a SEPARATE CiC session
CRITICAL CiC RULES -- READ BEFORE EVERY RUN
CAPTCHA: Watch for it on login. Solve it yourself then tell CiC to continue.
TABS: CiC may open a new tab and work there invisibly. Check ALL open tabs before assuming it is stuck.
SLOW: Pages take time to load. Wait 30 seconds before assuming it is frozen.
STUCK: Type "what tab are you on and what do you see right now"
STOP: Never hit stop without asking CiC for status first.
SAVE: If CiC finishes without saving type "save now before you continue"
INVISIBLE CHANGES: CiC can make changes that appear suddenly. This is normal. Let it finish.
MID-RUN: You can talk to CiC while it works. Use: "keep going", "check your other tabs", "save what you have done so far"
